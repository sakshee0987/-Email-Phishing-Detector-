# -Email-Phishing-Detector-


## Introduction
This project detects phishing emails using Python. It checks suspicious keywords and links inside email content.


# Working
1. User enters email content.
2. Program checks phishing keywords.
3. It checks suspicious links.
4. If suspicious content is found, it shows:
   "Phishing Email Detected"


   # Conclusion
This project helps understand basic phishing email detection using Python.


# How to Run

python phishing_detector.py
